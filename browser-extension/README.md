# MidaHoshi Anime Sync Bridge

Расширение Manifest V3 обнаруживает завершение эпизода в доступном HTML5-видеоплеере, показывает событие в popup и передаёт его в локальное приложение только после нажатия пользователя. Прогресс не записывается в библиотеку без подтверждения в самом приложении.

## Установка в Chrome / Chromium

1. Открой `chrome://extensions`.
2. Включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение».
4. Выбери папку `browser-extension` в репозитории.
5. Открой настройки расширения и проверь адрес приложения, обычно `http://127.0.0.1:5173`.

## Поддерживаемые источники

- AnimeGO: `anime-go.org`, `animego.online`.
- YummyAnime: `yummyani.me`, `yummy-ani.me`.
- Anixart: ручное событие с официальной веб-страницы можно отправить через popup, указав номер серии. Официальный сайт не предоставляет браузерный видеоплеер, а просмотр и ведение списков доступны в Android-приложении. Автоматическое обнаружение просмотра Anixart в браузере не поддерживается.

## Как работает автоматическое обнаружение

1. Content script считывает заголовок страницы, предполагаемый номер серии и метаданные HTML5-видео.
2. Когда видео достигает 90% длительности или завершается, событие попадает в локальную очередь расширения и на значке появляется счётчик.
3. Пользователь открывает popup, проверяет название и номер серии и нажимает «Передать».
4. Локальное приложение открывается с событием просмотра.
5. Пользователь выбирает тайтл из библиотеки и подтверждает обновление отдельной записи источника.

Если название или номер серии не удалось определить, можно нажать «Считать страницу» и заполнить данные вручную. Если видео находится в cross-origin iframe или сайт использует нестандартный плеер без доступного HTML5 video element, автоматическое обнаружение может быть недоступно.

## Безопасность

- Расширение не читает cookies, пароли, токены, localStorage аккаунтов или сетевые запросы сайтов.
- События остаются в локальном хранилище расширения до отправки в локальное приложение.
- Разрешения ограничены перечисленными доменами и адресом локального приложения.
- Расширение не обходит DRM, авторизацию или paywall.
