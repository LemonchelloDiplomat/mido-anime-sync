# MidaHoshi Anime Watch Bridge

Локальное Manifest V3 расширение для передачи завершённых эпизодов из поддерживаемых веб-плееров в открытую вкладку MidaHoshi Anime Sync.

## Установка для разработки

1. Открой Chrome или Chromium и перейди на `chrome://extensions`.
2. Включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение».
4. Выбери папку `browser-extension` в репозитории.
5. Открой приложение на `http://127.0.0.1:5173` или `http://127.0.0.1:3001`.

## Поддержка сайтов

- AnimeGO: экспериментальные DOM-адаптеры для `anime-go.org` и `animego.online`. Эти домены требуют проверки на реальных страницах пользователя.
- YummyAnime: экспериментальные DOM-адаптеры для официальных доменов `yummyani.me` и `yummy-ani.me`.
- Anixart: браузерный адаптер намеренно отключён. Официальная справка Anixart указывает, что просмотр и ведение списков доступны в Android-приложении, а сайт предназначен для загрузки приложения и публичных ссылок. Для полноценной поддержки нужен отдельный Android-мост либо подтверждённый пользователем официальный веб-плеер.

## Безопасность и ограничения

- Расширение не читает cookies, localStorage аккаунтов, пароли, токены или сетевые запросы сайтов.
- Никакие данные не отправляются на внешний сервер. События передаются только в локальную вкладку MidaHoshi Anime Sync через Chrome runtime messaging.
- Отправляется только событие, когда HTML5-видео достигло 90% длительности или завершилось.
- Прогресс не записывается автоматически: приложение показывает найденный тайтл и требует подтверждения пользователя.
- Сопоставление выполняется только по точному названию. При нуле или нескольких совпадениях приложение не выбирает запись самостоятельно.
- Разметка сайтов может меняться. Селекторы и домены должны проверяться на актуальных страницах перед выпуском.
