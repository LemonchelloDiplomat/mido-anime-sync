# MidaHoshi Anime Sync Bridge

Расширение Manifest V3 передаёт подтверждённое событие просмотра в локальное приложение через URL-параметр. Оно не получает пароли, cookies или токены сайтов и ничего не отправляет автоматически.

## Установка в Chrome / Chromium

1. Открой `chrome://extensions`.
2. Включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение».
4. Выбери папку `browser-extension` в репозитории.
5. Открой настройки расширения и проверь адрес приложения, обычно `http://127.0.0.1:5173`.

## Поддерживаемые источники

- AnimeGO: `anime-go.org`, `animego.online`.
- YummyAnime: `yummyani.me`, `yummy-ani.me`, исторические официальные домены `yummyanime.club` и `yummyanime.info`.
- Anixart: веб-страницы на anixartapp.com могут передать название и вручную введённый номер серии, но официальный сайт Anixart не предоставляет браузерный видеоплеер. Смотреть и вести списки можно в Android-приложении. Поэтому автоматическое обнаружение просмотра Anixart в браузере не обещается.

## Как работает

1. Content script считывает только заголовок страницы, предполагаемый номер серии и доступные метаданные HTML5-видео.
2. Пользователь проверяет название и номер серии в popup.
3. Только после нажатия «Передать» расширение открывает локальное приложение с событием просмотра.
4. В приложении пользователь вручную выбирает тайтл из библиотеки и подтверждает обновление source entry.

Если сайт изменит DOM, извлечение названия или серии может потребовать обновления адаптера. Расширение не обходит DRM, авторизацию, paywall и не читает содержимое cross-origin iframe.
