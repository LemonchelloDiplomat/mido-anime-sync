# MidaHoshi Anime Sync

Локальная аниме-библиотека с каталогом AniList, импортом MAL и отдельным API-сервером для будущей двусторонней синхронизации. Архитектура рассчитана на локальный запуск сейчас и перенос backend на публичный сервер позже.

## Требования
- Node.js 22+
- npm 10+

## Установка и запуск (Windows PowerShell)
~~~powershell
npm install
Copy-Item .env.example .env.local
npm run typecheck
npm test
npm run dev
~~~

Открой адрес Vite из терминала (обычно http://127.0.0.1:5173). Команда npm run dev запускает frontend и API-сервер вместе. API слушает только localhost на порту 3001.

## Настройка подключений

### MyAnimeList
1. Зарегистрируй приложение на https://myanimelist.net/apiconfig.
2. В качестве redirect URL укажи http://127.0.0.1:3001/api/auth/mal/callback.
3. Перенеси Client ID и Client Secret (если выдан) в .env.local:
   - MAL_CLIENT_ID=...
   - MAL_CLIENT_SECRET=...

### AniList
1. Создай приложение на https://anilist.co/settings/developer.
2. В качестве redirect URL укажи http://127.0.0.1:3001/api/auth/anilist/callback.
3. Перенеси Client ID и Client Secret в .env.local:
   - ANILIST_CLIENT_ID=...
   - ANILIST_CLIENT_SECRET=...

Не отправляй Client Secret, access token или refresh token в чат и не добавляй их в Git. Файл .env.local и папка .local-data исключены из Git.

## Локальная безопасность
- API по умолчанию привязан к 127.0.0.1, а не доступен всей локальной сети.
- OAuth-токены хранятся в .local-data/tokens.enc.json и шифруются AES-256-GCM отдельным локальным ключом.
- MAL OAuth использует PKCE; обмен кода на токен выполняет локальный сервер.
- AniList public catalog продолжает работать без авторизации; подключение аккаунта требуется для чтения и изменения личного списка. OAuth использует Authorization Code Grant, а обмен кода на токен выполняет локальный сервер.
- Для публичного размещения понадобится HTTPS, серверное хранилище токенов и настройка redirect URI под домен. Локальную папку данных нельзя переносить на публичный сервер.

## Уже реализовано
- Локальное хранение в IndexedDB, поиск и фильтры библиотеки.
- AniList public catalog, карточки и подробные страницы.
- Импорт MyAnimeList XML и XML.GZ, предварительный просмотр, backup и безопасное слияние.
- Обогащение каталожными метаданными AniList по точному MAL ID.
- Локальный API-сервер, health/status endpoints, OAuth-подключение MAL и AniList, зашифрованное хранение токенов.
- Чтение текущих списков подключённых аккаунтов через локальный API (MAL и AniList).
- Импорт личного списка напрямую из подключённого аккаунта с предварительным просмотром и резервной копией.
- Подготовка экспорта в MAL/AniList: сравнение локальных и удалённых статусов, прогресса и оценок; более свежие удалённые записи и неоднозначные конфликты пропускаются.
- Запись подтверждённых локальных изменений обратно в MAL/AniList. Отправляются только статус, прогресс и оценка.

## Следующие этапы интеграции
- Синхронизация избранного и дополнительных полей (теги, даты, комментарии, повторные просмотры).
- Экспорт/запись статусов, прогресса и оценок обратно в аккаунты.
- Безопасная синхронизация изменений с diff, конфликтами и подтверждением пользователя.
- Приоритет каталога и резервных источников для поиска, постеров и метаданных.
- Публичный backend и синхронизация между устройствами.

Пока не синхронизируются избранное и дополнительные поля MAL/AniList. Запись выполняется только для тайтлов с соответствующим внешним ID. Перед массовой отправкой приложение показывает количество изменений и отдельно пропускает записи, где удалённый сервис выглядит новее.


## Browser watch bridge (experimental)

Ветка `feat/streaming-site-bridge` содержит локальное расширение Chrome Manifest V3 в `browser-extension/`.

- Поддерживаемые экспериментальные веб-адаптеры: AnimeGO (`animego.lt`, `animego.name`) и YummyAnime (`yummyani.me`, `yummy-ani.me`).
- Расширение отправляет событие только после достижения HTML5-видео отметки 90% или события `ended`.
- Приложение показывает найденный тайтл и применяет прогресс только после ручного подтверждения и единственного точного совпадения названия.
- Если совпадение отсутствует или неоднозначно, запись не изменяется.
- Anixart пока не подключён к браузерному мосту: официальная справка описывает просмотр и управление списками как функции Android-приложения. Для него потребуется Android-интеграция либо подтверждённый пользователем официальный URL веб-плеера.
- DOM-селекторы и домены AnimeGO/YummyAnime считаются экспериментальными до проверки на реальных страницах. Если сайт меняет разметку, адаптер нужно обновить.

### Загрузка расширения

1. Выполни `npm run check:extension`.
2. Открой `chrome://extensions` и включи режим разработчика.
3. Нажми «Загрузить распакованное расширение» и выбери папку `browser-extension`.
4. Оставь открытой вкладку приложения на `http://127.0.0.1:5173` или `http://127.0.0.1:3001`.
