# MidaHoshi Anime Sync v0.2

Первая учебная версия ядра библиотеки. Работает локально, без логинов и подключения к сайтам.

## Требования
- Node.js 20+
- npm 10+

## Установка и проверка (Windows PowerShell)
```powershell
npm install
npm run typecheck
npm test
```

## Что реализовано
- Каноническая модель записи аниме.
- Нормализация статусов и оценок для шести будущих адаптеров.
- Обнаружение конфликтов.
- Локальное хранилище в JSON-файле через `JsonAnimeRepository`.
- Импорт и экспорт резервной копии JSON.
- Тесты ядра и хранилища.

## Пока НЕ реализовано
- Реальные подключения к шести сайтам.
- OAuth-авторизация.
- Браузерное расширение и Android-клиент.
- Автоматическая синхронизация между устройствами.

Сначала добиваемся надёжной локальной библиотеки, затем подключаем сервисы по одному.
