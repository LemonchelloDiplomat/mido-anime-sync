# MidaHoshi Anime Sync

Локальная аниме-библиотека с каталогом AniList, подробными страницами тайтлов и безопасным импортом списков.

## Требования
- Node.js 20+
- npm 10+

## Установка и запуск (Windows PowerShell)
```powershell
npm install
npm run typecheck
npm test
npm run dev
```

Открой адрес Vite, который появится в терминале (обычно `http://localhost:5173`).

## Уже реализовано

### Библиотека
- Локальное хранение в браузере через IndexedDB.
- Редактирование тайтлов и личных записей: статус, прогресс, оценка и избранное.
- Нормализованная модель для MyAnimeList, AniList, Shikimori, Anixart, AnimeGO и YummyAnime.
- Раздельное хранение записей каждого источника и обнаружение конфликтов.
- Поиск и фильтры по библиотеке.

### Каталоги и метаданные
- Поиск по публичному каталогу AniList без авторизации.
- Добавление тайтла в локальную библиотеку.
- Подробная страница AniList: описание, постер, баннер, рейтинг, жанры, студии и связанные произведения.
- Провайдеры метаданных подключаются через общий интерфейс, чтобы добавлять новые каталоги независимо от импорта/экспорта списков.
- AniList находит записи MyAnimeList по точному MAL ID пакетными GraphQL-запросами, без сопоставления по похожим названиям.
- После импорта MAL запускается обогащение библиотеки: названия, постер, год, формат, эпизоды, жанры, средний рейтинг и дата премьеры.
- Есть индикатор прогресса и повторный запуск для записей, которые не удалось найти.
- Обогащение не меняет личный статус, прогресс, оценку, избранное и исходные записи источников.
- Если постер не загрузился, карточка показывает аккуратную заглушку вместо сломанного изображения.

### Импорт и резервные копии
- Экспорт и импорт резервной копии JSON.
- Импорт MyAnimeList XML-экспорта, включая исходный файл `.xml.gz` без ручной распаковки.
- Предварительный просмотр сопоставлений перед слиянием.
- Перед слиянием создаётся резервная копия.
- Отсутствующие в импортируемом файле записи не удаляются.
- Статусы, прогресс, личные оценки и исходные данные источника сохраняются отдельно.

## Что ещё не реализовано
- Дополнительные провайдеры метаданных, включая Shikimori.
- Прямая авторизация и автоматическое чтение аккаунтов MyAnimeList и Shikimori.
- Подключение Anixart, AnimeGO и YummyAnime.
- Запись изменений обратно во внешние сервисы.
- Автоматическая синхронизация между устройствами.
- Браузерное расширение и Android-клиент.

Импорт MyAnimeList сейчас выполняется из XML или XML.GZ-файла, экспортированного самим пользователем. Распаковка ограничена 100 МБ. Приложение не запрашивает пароль и не изменяет данные на сайте.
